    Faites le tour avant la visite.

    Tournez autour de la maison, approchez la façade, la terrasse, la piscine, le jardin. D'une propriété à l'autre, la précédente redevient dessin, la suivante se construit.

    Du trait à la lumière.

    1. 01Le trait

      L'architecte pose les murs, les cloisons, les portes, les cotes. Le plan type A, 118 m², trois chambres.

    2. 02Le volume

      Le plan se couche, les murs montent. On lit enfin les distances, les passages, la lumière qui traverse.

    3. 03La matière

      Les sols, les meubles, les usages : le même plan, habité.

    4. 04La vie

      Et vous voilà dans le séjour, face au balcon.
